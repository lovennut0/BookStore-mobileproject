**Project Overview**

The Book Lab is a mobile application designed to be a bookstore application, but not including the transaction process. It provides users with an intuitive interface to sign in or create their account, select books into the cart, manage the cart inventory, record the order, and check stock levels based on the user purchase; all backed by a Supabase database for reliable data management.

**Features**

- Authentication: Sign up with Email, Username, and Password, Sign in with Email and Password and Reset a forgotten password via an email link sent through Supabase.
- Book Browsing: View available books with details on the Home and Book Detail screens, with search functionality to find specific titles.
- Cart Management: Add, update, and remove items before recording an order.
- Order Recording: Record placed orders and maintain order history.
- Stock Tracking: Check and reflect stock levels based on user purchases.

System Architecture Frontend: Developed with React Native for a cross-platform mobile interface. 

Language: TypeScript for both UI and application logic. 

Backend/Database: Supabase, used for authentication, storing books, orders, and user account records.

**Key Learning Outcomes**

- Implementation of authentication flows (sign up, sign in, forgot password) using Supabase.
- Integration of a React Native UI with a backend-as-a-service (Supabase) for data management.
- Structuring a mobile app with reusable components (buttons, bottom navigation) and screen-based routing.
- Understanding of client-side state management for cart and order handling, backed by database records.
